A small web API built with FastAPI, with two endpoints, run using Uvicorn.

Endpoints
GET / — returns a welcome message.
GET /greet/{name} — takes a name from the URL and returns a personalized greeting.

Student Grade System (Streamlit)

A simple web app version of the grade system, built with Streamlit.

What It Does

Enter a mark (0-100), click "Get Grade," and it shows the matching letter grade (A-E) based on the standard scale.
